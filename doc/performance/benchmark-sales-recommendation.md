## 完整成本結構分析

上述的「成本」僅計算了 Azure OpenAI 的 token 費用。但每次 `/sales/recommendation` API 呼叫實際上涉及多項 Azure 服務。以下是本訂閱下的完整成本結構。

│  └─ MCP → Cosmos DB Serverless (query_call_summary)                         │

├─────────────────────────────────────────────────────────────────────────────┤
│  Step 3: LLM 推薦話術生成                                                   │
│  └─ Container Apps (Orchestrator) → Azure OpenAI (GPT-5.2 / GPT-5-nano)    │

│  ├─ Azure App Configuration (Standard) — 讀取設定                           │
